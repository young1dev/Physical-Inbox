# Physical Inbox (A mini desk device that displays your important notification from 3rd part services)

Physical inbox is a mini desk device that shows messages with high priority. Good when you want to lock-in and don't want to miss important messages

## Why it was created

I created it for week 4 !(halflife.com)[HalfLife hackathon]. Physical inbox was more of a challenge project to build something combines both web development and hardware together.
